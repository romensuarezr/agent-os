# Ideas 2026-06-16

### Bug en close-sprint.sh (tubería grep -c)
- **Problema**: La expresión `TOTAL=$(grep -c "^| T-" "$SPRINT_FILE" 2>/dev/null || echo "0")` produce `0\n0` si no hay coincidencias, porque `grep -c` imprime `0` y sale con exit status 1, activando el `echo "0"`. Esto rompe las comparaciones numéricas de bash.
- **Solución**: Usar `TOTAL=$(grep -c "^| T-" "$SPRINT_FILE" || true)` o evaluar el exit status por separado, o usar `grep -cE` permitiendo un fallback seguro sin duplicación.
