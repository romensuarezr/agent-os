# Inventario de Habilidades de agent-os

Este archivo mantiene el registro y la documentación de las habilidades (skills) del agente en el proyecto.

## Lista de Habilidades Activas

### 1. Remote Admin (`remote-admin`)
- **Para qué sirve**: Ejecución remota de comandos, diagnósticos y gestión de contenedores Docker en servidores/VPS vía SSH de forma segura.
- **Cómo invocar**: `ssh <alias> "<comando>"` (ej: `ssh datamanager "docker ps"`)
- **Ubicación**: `.agents/skills/remote-admin/`
