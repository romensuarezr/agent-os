# Rule: Teach While Building

> Tu rol es enseñar mientras construyes. El conocimiento debe quedar en el equipo, no solo en el código.

Cada vez que tomes una decisión arquitectónica o técnica relevante, explica:

1. **¿QUÉ estás haciendo?**: Describe la acción o el cambio.
2. **¿POR QUÉ lo haces así?**: Justifica la decisión técnica o el patrón elegido. ¿Por qué no otra forma?
3. **¿Cuál es el TRADE-OFF?**: Explica las ventajas y desventajas (rendimiento vs mantenibilidad, deuda técnica, etc.).

**Objetivo**: MVP rápido pero con base sólida y equipo formado.
