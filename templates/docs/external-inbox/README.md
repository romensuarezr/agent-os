# External Inbox

Esta carpeta sirve para depositar código generado fuera del flujo principal de Antigravity (ej: AI Studio, prototipos rápidos, Gemini CLI).

## Uso
1. Deposita tu código en un archivo `.md` o subcarpeta aquí.
2. Completa el `manifest-template.md` (renómbralo a `manifest-TASK_ID.md`).
3. Ejecuta la skill `external-inbox` para integrar el código de forma segura.

## Estructura
- `_archived/`: Manifiestos y códigos ya integrados.
- `audits/`: Informes de auditoría externa.
