# Idea Inbox

Esta carpeta sirve para capturar ideas, preguntas o sugerencias que surgen durante las sesiones de desarrollo pero que no forman parte de la tarea activa.

## Uso
- Durante una sesión, el agente captura la idea en un archivo nombrado por fecha: `YYYY-MM-DD.md`.
- Durante el `/sprint-planning`, estas ideas se revisan y se mueven al `ROADMAP.md` o se descartan.

## Formato de entrada
```markdown
- **Idea:** [descripción]
- **Impacto estimado:** Poco / Mucho
- **Contexto:** [archivo o tarea activa]
- **Capturado:** YYYY-MM-DD HH:MM
```
